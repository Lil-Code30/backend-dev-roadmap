This question involves a digital stopwatch that tracks time in minutes and seconds. The Stopwatch class, which you will write, is used to manage a single stopwatch.

The Stopwatch class contains a constructor and three methods.

  • The constructor has no parameters. The stopwatch always begins at 0 minutes and 0 seconds in a stopped state (not running).
  • The start method has no parameters. If the stopwatch is already running, the method does nothing. If the stopwatch is stopped, it begins running. The start method does not return a value.
  • The click method has no parameters and simulates one second passing. If the stopwatch is stopped, the method does nothing. If the stopwatch is running, the time increases by 1 second. When the seconds reach 60, they reset to 0 and the minutes increase by 1. The click method does not return a value.
  • The stop method has no parameters. If the stopwatch is running, it stops running and returns a String showing the elapsed time in the format mm:ss where mm is the minutes (always shown with at least 2 digits, using leading zeros if necessary) and ss is the seconds (always shown with exactly 2 digits, using a leading zero if necessary). If the stopwatch was already stopped when stop is called, it returns the same formatted time as it had when it was originally stopped and the stopwatch remains stopped.
