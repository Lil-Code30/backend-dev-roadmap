This question involves managing swim classes at a swim school. A swim school tracks swim classes throughout the day. The SwimClassSchedule class represents the swim class portal, and the SwimInstructor class uses SwimClassSchedule objects to manage classes and generate instructor bio summaries. The SwimClassSchedule class is provided in the assignment and has already been implemented.

A swim instructor is associated with a swim class schedule and is represented by the SwimInstructor class. You will write two methods of the SwimInstructor class.

a. Write the scheduleStudents method, which attempts to schedule students in a swim class specified by className across time slots from startSlot to endSlot, inclusive. For each time slot in the range, the method attempts to schedule an amount of studentsPerSlot students in the specified swim class.

For each time slot, students can only be scheduled if adding the amount of studentsPerSlot students would not exceed the class's capacity. If scheduling the students would exceed capacity, no new students are scheduled for that time slot. If scheduling the students keeps the total number of students at or below capacity for that class, the students are scheduled for that time slot.

The method returns the total number of new students successfully scheduled across all time slots for the class specified in the range. The following table shows examples of scheduleStudents behavior. Assume the SwimInstructor object teacher is associated with a swim schedule and that Guppies has a capacity of 4 students.

Time Slot Current Number of Students Number of Students Scheduled After scheduleStudents("Guppies", 5, 8, 2) Explanation
5 1 3 There is 1 student currently scheduled in the Guppies class at time slot 5. The capacity for the Guppies class is 4 students, so the 2 new students can be scheduled to make a total of 3 students scheduled in this class during this time slot.
6 3 3 There are 3 students currently scheduled in the Guppies class at time slot 6. The capacity for the Guppies class is 4 students, so the 2 new students cannot be scheduled keeping the total at 3 students scheduled in this class during this time slot.
7 2 4 There are 2 students currently scheduled in the Guppies class at time slot 7. The capacity for the Guppies class is 4 students, so the 2 new students can be scheduled to make a total of 4 students scheduled in this class during this time slot.
8 0 2 There are 0 students currently scheduled in the Guppies class at time slot 8. The capacity for the Guppies class is 4 students, so the 2 new students can be scheduled to make a total of 2 students scheduled in this class during this time slot.

The method call teacher.scheduleStudents("Guppies", 5, 8, 2); would return 6 (2 + 0 + 2 + 2 = 6 additional students successfully scheduled by calling the method).

As another example, consider a class, Sharks, with a capacity of 3 students:

2 0 3 There are 0 students currently scheduled in the Sharks class at time slot 2. The capacity for the Sharks class is 3 students, so the 3 new students can be scheduled to make a total of 3 students scheduled in this class during this time slot.

4 3 3 There are 3 students currently scheduled in the Sharks class at time slot 4. The capacity for the Sharks class is 3 students, so the 3 new students cannot be scheduled keeping the total of 3 students scheduled in this class during this time slot.
5 0 3 There are 0 students currently scheduled in the Sharks class at time slot 5. The capacity for the Sharks class is 3 students, so the 3 new students can be scheduled to make a total of 3 students scheduled in this class during this time slot.

The method call teacher.scheduleStudents("Sharks", 2, 5, 3); would also return 6 (3 + 0 + 0 + 3 = 6 additional students successfully scheduled by calling the method).

Complete the method scheduleStudents. You must use getStudentCount, getClassCapacity, and bookClass appropriately to receive full credit.

b. Write the getInstructorBioSummary method, which returns a swim instructor's bio summary based on the instructor's name and bio. The bio summary is constructed according to the following rules:
  • The bio summary includes only the first name and first initial of the last name of the swim instructor.
  • The bio summary includes BSI if the instructor has a Basic Swim Instructor certification and WSI if the instructor has a Water Safety Instructor certification. You may assume these are the only two options for instructor certification.
  • The bio summary includes the number of years the instructor has been certified.
