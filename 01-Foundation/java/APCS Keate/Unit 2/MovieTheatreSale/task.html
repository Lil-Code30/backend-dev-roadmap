Movie Theatre Sale

When you go to the movies, there are various tickets you can buy. For example, only those 17 and over can purchase a rated R movie ticket. Additionally, discounts are usually given to children and seniors and for matinee showings.

Assignment:
Write a program to have a movie theatre cashier prompt the user and calculate the total sale of a set of movie tickets.

1. Fill in all the getter methods to return the instance variables.
2. Create a method, checkID, that records the customer's ID age is valid if the movie is rated R. The user should be asked to enter the birth year on the ID to test if the ID is valid. This method should return a boolean.

You will be using this method in the client class to determine whether to proceed with the sale.

3. Write a method, getTotalSale, to calculate and return the total sale for tickets for a customer. The sale should account for appropriate discounts when necessary.
4. Fill in the client class asking the customer for the title of the movie, rating of the movie, the time of the movie, and the number and type of tickets.
Be sure to remember to use Scanner class methods found in its API. Also, use the correct import statements in the class where you use Scanner methods.
The time needs to be converted to military time to easily distinguish between AM and PM. 2:00pm in military time is entered as 14:00 but must be saved as 1400.
You should check the time and determine if the show is a matinee showing (before 2:00pm). If so, the total number of tickets should also be the total number of matinee tickets as this is the cheapest discount. The rest of the types of tickets should be set to zero (you will not need to ask the user how many of each type of these there are). For any showing after 2:00pm, the number of matinee tickets should be set to zero and you will need to ask for the number of each type of ticket.

5. Create a MovieTheatreSale object in the client class being sure to run the checkID method to make sure only those over 17 can buy tickets to rated R movies. If someone under 17 tries to buy a ticket, a message should be printed, indicating the sale is over, and the program should terminate.
An example of how to terminate a program is shown in first part of the client class when the total tickets do not match the number of adult, child, and senior tickets.

6. Verify that the program gives an explanatory message and quits when the number of adult, child, and senior tickets does not match the total number of tickets.
7. Verify that the program gives an explanatory message and quits when trying to sell rated R tickets for someone under 17.
8. Verify that the program gives the correct sale for the following information. The birth year of the customer is 2007.
Movie: Schindler's List
Rating: R
Showtime: 15:00
Total tickets: 3
Number of adult tickets: 2
Number of child tickets: 0
Number of senior tickets: 1
The total sale should be $34.60.
9. Verify that the program gives the correct sale for the following information. The birth year of the customer is 2000.
Movie: Toy Story
Rating: G
Showtime: 11:00
Total tickets: 5
Number of adult tickets: 2
Number of child tickets: 2
Number of senior tickets: 1
The total sale should be $41.00.
10. Verify that the program gives the correct sale for the following information. The birth year of the customer is 2000.
Movie: Super Mario Bros
Rating: PG
Showtime: 16:00
Total tickets: 5
Number of adult tickets: 2
Number of child tickets: 2
Number of senior tickets: 1
The total sale should be $56.00.
11. Fill in the comments at the top of each class with your name and pertinent information.
