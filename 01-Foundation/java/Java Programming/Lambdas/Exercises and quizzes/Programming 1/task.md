# Réalisation d'une interface avec une classe anonyme, une expression lambda et une référence de méthode 
Nous souhaitons mettre en place un trieur de `String` personnalisé, comme 
défini dans la réalisation de la classe concrète `MyComparator`. Cette 
classe réalise l'interface générique `Comparator<String>`. 

La classe `Main` réalise le tri en utilisant une instance de la classe 
`MyComparator`. Complétez la classe `Main` de sorte qu'on puisse 
reproduire le même tri avec une classe anonyme, une expression lambda et une 
référence de méthode.
