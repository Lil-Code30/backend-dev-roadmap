# Digits only !

La méthode `filterDigit()` doit filtrer le contenu du  
paramètre de type `String` reçu en paramètre pour ne conserver que les 
chiffres (de `"0"` à `"9"`). La méthode doit donc retourner une chaîne de 
caractères ne contenant que ces chiffres. 

Afin d'éviter de nombreuses concaténations coûteuses en utilisant des 
instances de `String`, il est recommandé d'utiliser la classe 
`StringBuilder` dans la méthode `filterNumber()`.
