# Palindrome or not ?

L'objectif est de déterminer si une instance de `String` est un palindrome.
Un palindrome est un mot ou groupe de mots qui peut se lire indifféremment de 
gauche à droite ou de droite à gauche en gardant le même sens (ex. "la mariée 
ira mal").

Dans le programme "Main.java", la méthode `palindrome()` doit retourner `true` 
si la chaîne de caractères passée en paramètre est un palindrome, `false` 
autrement.
