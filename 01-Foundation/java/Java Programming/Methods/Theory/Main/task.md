# Méthode main

La méthode `main` est le point d'entrée d'une application Java. Elle est donc 
invoquée par la machine virtuelle lors du lancement de l'application.

Elle reçoit en paramètre un tableau de String contenant éventuellement les 
valeurs des paramètres nécessaires au lancement du programme.

Sa signature est imposée et sa réalisation est requise. C'est pour cela 
que tous les programmes créés jusqu'ici contiennent cette méthode.
