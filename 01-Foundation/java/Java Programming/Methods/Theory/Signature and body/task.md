# Signature et corps de la méthode

Les méthodes sont constituées d'une **signature** (ou en-tête) et d'un 
**corps de méthode** qui se présentent de la manière suivante :
```
signature {
  corps_de_méthode
}
```

En bref:
- La **signature** définit tout ce qui est nécessaire de connaître pour 
  utiliser la méthode.
- Le **corps de la méthode** contient toutes les instructions exécutées lors de 
  l'utilisation de la méthode.

L'utilisation d'une méthode s'appelle **l'invocation** ou aussi **l'appel**.
