# Le mot-clé `this`

Le mot-clé `this` est utilisé pour référencer l'objet à l'intérieur duquel le 
code est exécuté. 

On peut considérer que l'objet `this` est implicitement passé en référence 
lors de l'invocation de chaque méthode de la classe.

À l'intérieur du corps de la méthode, on peut utiliser le mot-clé `this` 
pour référencer l'objet sur lequel la méthode a été invoquée.

## Exemple : les classes `Point` et `Main`
Dans cet exemple, la classe `Point` contient une méthode `distanceOrigin`. 
Celle-ci utilise le mot-clé `this` pour afficher les valeurs des attributs 
`px` et `py` du point.
