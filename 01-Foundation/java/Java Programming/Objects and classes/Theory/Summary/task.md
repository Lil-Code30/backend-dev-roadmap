# Résumé

En résumé, écrire une classe c'est : 
- Choisir un nom pour la classe. 
- Écrire la spécification : écrire la signature des méthodes avec les 
  exceptions prévues et expliquer l'effet attendu de chaque méthode.
- Écrire une implémentation : définir les attributs puis écrire le corps de 
  chaque méthode.
- Tester le bon fonctionnement.
- Et éventuellement documenter la classe avec `/** ... */`, optimiser, ...

Ces notions sont exercées dans les exercices qui suivent et dans les séries 
pratiquées en classe.
