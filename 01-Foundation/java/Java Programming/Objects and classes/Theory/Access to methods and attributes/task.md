# Accès aux attributs et méthodes de la classe

L'accès aux membres des objets s'effectue en utilisant l'opérateur point `.` 
selon la syntaxe suivante :
```
nom_de_l_objet.nom_du_membre
```

`nom_du_membre` représente soit un champ/attribut, soit une méthode.

## Exemple : les classes `Point` et `Main`
La classe `Main` indique comment accéder aux attributs et méthodes du point 
`p1`. Précédemment, il était indiqué que chaque objet possédait son propre 
état. C'est ainsi que `p1` et `p2` sont deux objets distincts avec des valeurs 
d'attributs distinctes. Un des attributs de `p1` est d'ailleurs modifié tandis 
qu'aucune modification n'est amenée à `p2`.
