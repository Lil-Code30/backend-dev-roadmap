# Boucles `for` imbriquées

Vous devez écrire un programme qui imprime le rectangle suivant sur la console :

<pre>
----------------------------------<br>|                                |
|                                |   
|                                |
|                                |
----------------------------------
</pre>

Le long côté est composé de 34 `'-'` et le côté court de 4 `'|`.

<div class="hint">
  Vous devez probablement utiliser deux boucles imbriquées pour imprimer ce 
rectangle. La boucle interne doit probablement utiliser des <b>if</b>, afin de 
sélectionner le caractère à imprimer pour une itération donnée.
</div>
