# Boucle `while` et instructions `break` et `continue`

Le programme "Main.java" simule un congélateur. Le congélateur est enclenché à 
une température de 50 degrés. Il doit afficher la température lorsque 
celle-ci est inférieure ou égale à 20 degrés. Lorsque la température de 0 degré 
est atteinte, il doit afficher "Temperature ok!" et terminer.

Complétez le programme en utilisant une instruction `if`, une instruction 
`break` et une instruction `continue` pour un fonctionnement correct du 
programme.
