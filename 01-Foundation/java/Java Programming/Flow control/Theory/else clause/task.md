# La clause `else` suivant une instruction `if`

Dans le cas où il est nécessaire d'exécuter une portion d'instructions si la 
condition de l'instruction `if (cond)` est évaluée à `true` **et** une autre 
réaction dans le cas où la condition est évaluée à `false`, il 
est alors utile d'utiliser la clause `else` :

<pre><code>
if (cond) {
  ...  
} else {
  ...
}
</code></pre>
