# L'imbrication d'instructions `if`

Les instructions de contrôle de flux peuvent bien sûr s'imbriquer et créer 
ainsi des programmes avec de nombreuses branches possibles. Dans ce cas, les 
conditions pour exécuter les blocs d'instructions se combinent et il est 
utile de documenter les conditions causant l'exécution d'un bloc 
d'instructions. 

# Exercice

Dans l'exemple de code donné dans le programme "Main.java", les
conditions sont documentées à l'exception d'une. Complétez la condition manquante
et identifiez la proposition relative.
