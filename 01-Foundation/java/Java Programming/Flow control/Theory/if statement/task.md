# L'instruction `if`

Une instruction de contrôle de flux très utilisée est l'instruction `if 
(cond)`, qui est une instruction de sélection qui détermine si une portion 
d'instructions doit être exécutée ou non.

Le principe est simple : dans l'instruction `if (cond)`, `cond` est une 
expression qui doit pouvoir être évaluée comme un `boolean`. Si 
l'expression est évaluée à `true`, alors la portion qui suit 
le `if (cond)` sera exécutée. Dans le cas contraire, cette portion ne sera pas exécutée.

## L'utilisation des `{}`

La portion suivant l'instruction `if (cond)` peut être constituée
d'une seule instruction sans `{}` ou alors d'un bloc d'une ou plusieurs instructions 
entourées de `{}`. Une pratique recommandée est de toujours utiliser `{}` à 
la suite d'une instruction de contrôle de flux.
