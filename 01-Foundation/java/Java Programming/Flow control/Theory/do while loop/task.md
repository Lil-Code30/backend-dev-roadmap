# L'instruction `do ... while`

Un autre type de boucle similaire à la boucle `while` est la boucle :

```
do {

} while (condition);
```

Cette boucle est similaire à la boucle `while`, si ce n'est que le bloc 
d'instructions sera toujours exécuté au moins une fois. 

# Exemple
L'exemple de programme "Main.java" démontre une utilisation de cette boucle. 
Dans ce programme, un nombre aléatoire `intNumber` compris entre 0 et 10 est 
généré. Tant que ce nombre n'est pas égal à 5, un nouveau nombre est tiré.
L'utilisation d'une boucle `do...while()` est donc naturelle, puisque l'on 
doit tirer un nombre aléatoire au moins une fois.
