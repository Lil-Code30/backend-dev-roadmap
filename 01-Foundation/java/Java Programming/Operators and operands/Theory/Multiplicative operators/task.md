# Les opérateurs multiplicatifs
Les **opérateurs multiplicatifs** sont les opérateurs arithmétiques 
permettant de réaliser des multiplications et des divisions. Les opérandes 
des opérateurs arithmétiques peuvent être de type entiers ou de type à 
virgule flottante.

Les opérateurs multiplicatifs sont binaires :

- `*` : Multiplication
- `/` : Division (division entière, resp. division en nombre à virgule)
- `%` : Modulo

Les opérateurs multiplicatifs peuvent également être utilisés avec des opérandes
de type `char`, ce qui impliquera une conversion implicite vers un
type `int`.
