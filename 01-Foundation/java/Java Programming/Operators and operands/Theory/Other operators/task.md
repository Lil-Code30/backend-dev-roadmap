# L'opérateur `instanceof`

L'opérateur `instanceof` est utilisé pour tester si un objet est une
instance d'une certaine classe ou d'une interface. L'opérateur retourne une
valeur de type `boolean` et s'exprime sous la forme :

`object instanceof class_or_interface_name`
