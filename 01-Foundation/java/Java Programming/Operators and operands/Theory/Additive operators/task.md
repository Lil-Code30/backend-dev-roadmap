# Les opérateurs additifs 

Les **opérateurs additifs** sont les opérateurs arithmétiques permettant de 
réaliser des additions, soustractions, des incrémentations et décrémentations. 
Les opérandes des opérateurs arithmétiques peuvent être de type 
entiers ou de type à virgule flottante. 

Les opérateurs additifs peuvent être binaires ou unaires :
- `+` : Addition (binaire)
- `–` : Soustraction (binaire)
- `++` : Incrémentation (unaire). Il y a deux sortes d'opérateurs 
  d'incrémentation :
  - Post-Increment : la valeur de l'opérande est d'abord utilisée pour
    calculer le résultat de l'expression puis la valeur de l'opérande est
    incrémentée.
  - Pre-Increment : la valeur de l'opérande est d'abord incrémentée, puis le
    résultat de l'expression est évaluée.
- `--` : Décrémentation (unaire). Les deux mêmes sortes d'opérateurs (Post/Pre)
  existent.

Les opérateurs additifs peuvent également être utilisés avec des opérandes 
de type `char`, ce qui impliquera une conversion implicite vers un 
type `int`.
