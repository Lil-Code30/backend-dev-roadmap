# Les opérateurs relationnels

Les **opérateurs relationnels** sont des opérateurs binaires utilisés pour 
tester les relations d'égalité ou d'inégalité (plus grand, plus petit). Le 
résultat de l'opération produit une valeur booléenne. Par exemple, 
l'opérateur `==` (égalité) retourne `true` si les deux opérandes sont égaux. 
Les autres opérateurs sont :

- `!=` (Inégalité)
- `<`
- `<=`
- `>`
- `>=`

## Les relations entre nombres à virgule flottante
Lorsque les opérandes sont des types à virgule flottante, il est important 
de ne pas oublier qu'une valeur à virgule flottante est une approximation 
d'un nombre réel et que cette approximation peut être différente en fonction 
de la taille du type (`float` ou `double`) ou de l'ordre dans lequel sont effectuées les 
opérations.
