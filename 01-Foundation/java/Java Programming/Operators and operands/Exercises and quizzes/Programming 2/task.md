# Multiple d'un nombre

Un problème courant dans un programme est de déterminer si un nombre est un 
multiple d'un ou plusieurs autres nombres. Le fait de déterminer si un 
nombre est le multiple d'un autre nombre est possible avec une seule 
opération à l'aide d'un opérateur arithmétique.

Dans la méthode `main`, complétez le code qui permet de vérifier si `z` est 
un multiple de `x` et de `y`. L'expression doit être la même dans les deux 
cas testés.
