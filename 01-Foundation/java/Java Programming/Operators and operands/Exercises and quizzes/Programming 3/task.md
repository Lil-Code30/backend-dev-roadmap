# Extraire le chiffre des dizaines dans un nombre

Soit un nombre entier `N` positif. Trouvez le nombre de dizaines `d` comprises 
dans le nombre, selon les exemples ci-dessous. L'expression doit bien sûr être
chaque fois la même pour les exemples donnés.

```
N = 173 -> d == 7
N = 7 -> d == 0
N = 63 -> d == 6
```
