# Extraire la première décimale d'un nombre à virgule flottante

Soit un nombre à virgule flottante `X`. Trouvez le premier chiffre `d` 
après la virgule, selon les exemples ci-dessous. L'expression doit bien sûr être
chaque fois la même pour les exemples donnés.

```
X = 1.79 -> d == 7
X = 0.01 -> d == 0
X = 17.89 -> d == 8
```
