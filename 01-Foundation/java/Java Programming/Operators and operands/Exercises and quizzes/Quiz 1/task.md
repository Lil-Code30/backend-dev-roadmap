# Evaluation d'une expression

Evaluez la valeur de `e` dans l'extrait de code ci-dessous :
```
int a = 1, b = 2, c = 3, d = 4;
int e = a+++b-++c/d*a--<<++a&d*--b+a;
```

Réécrivez le code en ajoutant les parenthèses requises sur une feuille de 
papier ! Vous pouvez également décomposer l'expression pour calculer `e` 
dans la fonction `main`.
