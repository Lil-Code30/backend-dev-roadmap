# Conversions et arrondis

Le programme "Main.java" déclare une variable de type `double` initialisée 
avec la valeur `16.75`.

Complétez le code afin d'afficher la partie décimale du nombre sur la 
console, c'est-à-dire `0.75`

<div class="hint">
  Afin d'afficher la partie décimale, vous devez enlever (c'est-à-dire 
soustraire) la partie entière du nombre.
</div>
