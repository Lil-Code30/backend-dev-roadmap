# Conversions et arrondis

Le programme "Main.java" déclare une variable `d1` de type `double` initialisée
avec la valeur `16.9`.

Complétez le code afin que la variable `i1` de type `int`contienne la valeur de
`d` arrondie à la valeur entière la plus proche de `d1` (c'est-à-dire `17`).

Validez votre réalisation en arrondissant `d2` de la même manière (pour 
obtenir cette fois `16`).

<div class="hint">
  La conversion d'un nombre à virgule flottante vers un nombre entier 
tronque la partie décimale. En convertissant <code>16.9</code> en <code>int</code>, 
la valeur <code>16</code> est obtenue - ce n'est pas l'entier le 
plus proche de <code>16.9</code>. Que faut-il donc faire pour obtenir la 
valeur <code>17</code> ? La solution choisie doit permettre d'obtenir 
<code>16</code> pour l'arrondi de <code>d2</code>. 
</div>
