# Le type `char`

## Les valeurs littérales
Afin d'initialiser une variable avec une valeur prédéfinie, il est 
nécessaire d'utiliser les valeurs littérales existantes pour le type de la 
variable. Pour le type `char`, les valeurs littérales sont celles 
représentant un caractère normal ou spécial entre apostrophes `' '`, à ne 
pas confondre avec `" "`.

# Exercice
Dans la méthode `main` de votre programme, définissez une variable de type 
`char` qui prend la valeur du caractère _A_, et une autre variable qui prend 
la valeur du caractère spécial pour un saut de ligne. Affichez ensuite sur la 
console la première variable suivie de la deuxième, suivie encore de la première.


---
> **&#9432;** Les valeurs définies entre guillemets `" "` sont utilisées pour 
définir des valeurs littérales du type `String` et non `char`.
---

<div class="hint">
  Afin de vous assurer que l'expression affichée sur la console est bien une 
chaîne de caractères, vous devez précéder la concaténation des variables avec
l'expression <code>""</code> (valeur littérale d'une chaîne de 
caractères vide). Sans l'ajout de cette expression, les caractères sont 
convertis en valeurs entières et le <code>+</code> opère 
comme une addition de valeurs entières.
</div>
