# Programmation orientée objet

On veut réaliser un programme qui représente des montres et les gens qui les 
portent.

Une montre donne l'heure et les minutes.
- On peut initialiser une montre à partir d'un couple heure/minute.
- On peut initialiser une montre à partir d'une autre montre.
- Il doit être possible d'avancer l'heure d'une montre en ajouter une minute 
  (attention, les minutes sont limitées à 60 et les heures à 24).

Une personne a un nom et peut éventuellement porter une montre.
- On peut initialiser une personne à partir de son nom
- On peut initialiser une personne à partir de son nom et de sa montre.
- Il doit être possible de faire porter une montre à la personne (ou une 
  autre montre si elle en a déjà une).

Complétez les classes `Person` et `Watch` de sorte que la classe `Main` 
compile et s'exécute sans erreur. Pensez également à respecter les 
principes d'encapsulation et de programmation orientée objet.
