# Librairie de classes Java

La plateforme Java comprend une vaste collection de classes prédéfinies qui 
peuvent être utilisées indépendamment de l'environnement d'exécution des 
applications.

Cette librairie de classes est organisée en paquetages et sous-paquetages 
qui rassemblent, par domaine, des classes apparentées.

L'arborescence des paquetages de la plateforme Java possède deux racines 
principales, `java` et `javax`.

---
**&#9432;** Inutile de réinventer la roue. Avant de coder une fonction 
particulière, il faut s'assurer qu'elle n'est pas disponible dans la 
bibliothèque des classes standard.
---

# Exemple
Observez dans le programme "Main.java" comment les classes `ArrayList` et 
`List` faisant partie de la librairie `java.util` sont utilisées.
