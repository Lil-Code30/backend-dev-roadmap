# Utilisation des types `Enum` pour représenter un calendrier

Nous souhaitons représenter un calendrier. Une page (`Page`) possède une 
saison (`Season`) et un mois (`Month`). La saison commence par l'hiver pour 
finir par l'automne. Les mois vont de janvier à décembre.

Le calendrier est représenté par `Calendar`. Son constructeur initialise un 
calendrier comportant 12 pages (un par mois).

Complétez les classes et énumération afin que le `Main` puisse compiler et 
fournir l'output désiré.
