# Classe générique
On souhaite modéliser un arbre portant des objets entre autres des fruits 
(_Fruits_) ou des boules de Noël (_Bauble_). Les objets n'ont pas de 
comportement particulier. L'arbre possède une méthode d'ajout et de retrait 
des objets. 

Quelle est la meilleure façon de modéliser afin que le code soit clair et 
concis ?
