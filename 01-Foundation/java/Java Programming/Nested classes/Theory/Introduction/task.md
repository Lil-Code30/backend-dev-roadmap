# Introduction

Jusqu'à présent, les classes que nous avons vues étaient toutes des classes de 
premier niveau, c'est-à-dire des membres directs des paquetages, sans 
imbrication. Cependant, le langage Java permet de définir des classes à 
l'intérieur d'autres classes. On parle dans ce cas de **classes internes** 
(_nested class_). Il existe quatre types de classes internes : 
- Les classes membres statiques (_static nested class_)
- Les classes membres (_inner class_)
- Les classes locales (_local inner class_)
- Les classes anonymes (_anonymous inner class_)

Dans ce cours, nous nous attardons seulement sur les classes anonymes.
