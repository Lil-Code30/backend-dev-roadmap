# Méthode abstraite

Une méthode abstraite est une méthode qui ne contient pas de corps. Elle ne 
possède que la signature de définition suivie du `;`. 
```
public abstract double area(); // Example of an abstract method
```

Une classe possédant une ou plusieurs méthodes abstraites devient 
obligatoirement une **classe abstraite**. Cette classe est déclarée avec le 
modificateur `abstract`. 

Les classes abstraites sont étudiées dans ce présent chapitre.

# Exemple
La classe `Dummy` est déclarée avec le modificateur `abstract` puisqu'elle 
contient une méthode abstraite.
