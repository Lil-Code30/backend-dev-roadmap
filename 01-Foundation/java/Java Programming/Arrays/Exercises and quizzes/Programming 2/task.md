# Tableaux multi-dimensionnels

Complétez le programme "Main.java" afin d'afficher le résultat suivant :
```
*****
****
***
**
*
```

Pour ceci, utilisez un tableau de caractères à deux dimensions dont la 
longueur de la base (c'est-à-dire le nombre d'étoiles sur la première ligne) 
est définie d'avance.

Pour l'affichage, essayez de n'utiliser que des `for each`.
