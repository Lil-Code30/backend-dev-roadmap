# Tableaux multi-dimensionnels

Analysez le programme "Main.java" et établissez les valeurs de :
```
// One
one.length
one[1]
// Two
two.length
two[2].length
two[2].length
two[1]
two[1][2]
// Three
three.length
three[0].length
three[0][0].length
three[1][2]
three[1][2][2]
```

Comparez vos réponses en lançant le programme.

Jouez avec les index si nécessaire pour bien comprendre l'accès aux différentes
dimensions et valeurs.
