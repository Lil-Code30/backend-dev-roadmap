# Introduction aux tableaux

Imaginons que nous souhaitions sauvegarder et afficher les cinq premiers nombres 
premiers. Une manière consiste à utiliser une variable pour chaque nombre 
premier, comme dans les lignes 3 à 15 du programme "Main.java". Néanmoins, 
il s'agit d'une solution peu pratique. Imaginez que nous devrions afficher 
les 20 premiers nombres complexes avec 20 variables...

Dans ce cas, les tableaux s'avèrent très utiles comme démontré aux lignes 18 
à 22. Ils permettent de sauvegarder des valeurs **du même type** dans un 
certain ordre. Autrement dit, un tableau est une séquence indexée d'éléments 
de même type. Il est caractérisé par :

- sa taille (le nombre d'éléments qu'il peut contenir)
- le type de ses éléments

Les deux sections suivantes expliquent plus en détails comment déclarer et 
initialiser les tableaux.
