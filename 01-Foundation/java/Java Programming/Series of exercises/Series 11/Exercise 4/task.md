# Exercice 4 de la série 11

Ecrire un programme qui réalise un cryptage poly-alphabétique.

La clé de codage sera constituée d'une chaîne de caractères
(uniquement des lettres majuscules entre 'A' et 'Z'). Le programme recevra
en paramètre le nom d'un fichier texte (<nom>.txt) ainsi que la clé de
codage et créera en sortie le fichier crypté (<nom>.vig).

---
**&#9432;**
Afin de tester votre solution correctement, suivez attentivement les
instructions données ci-dessous.
---

## Instructions :
Vous devez implémenter les méthodes `main()` et `vigenereCypher()`, en
respectant les points suivants :
- Le contenu du fichier codeWithVigenere.txt ne doit pas être modifié.
- Le programme doit pouvoir encoder et décoder.
- Si le fichier source contient des retours à la ligne, ces retours à
  la ligne doivent également être présents dans le fichier chiffré/déchiffré.

### Tester votre solution
Afin de tester votre solution (avant de la tester avec le bouton "Check"),
vous pouvez exécuter le programme "Main.java".
