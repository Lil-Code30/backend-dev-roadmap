# Exercice 1 de la série 8

Écrire une méthode qui reçoit en paramètre un tableau d'entiers, à deux
dimensions, et qui affiche son contenu sous la forme suivante :

```
0 : 17 23 4 11
1 : 8
2 : 62 5 9
3 :
4 : 134 67 8 19
...
```
**&#9432;**
La méthode doit s'appeler `print2DArray` et reçoit un tableau de deux dimensions en
paramètre (appelée dans `main`).

<div class="hint">
    <b>Vérifiez votre implémentation :</b><br>
    <ul>
        <li>La méthode doit s'appeler <b>print2DArray</b>.</li>
        <li>Elle ne doit pas retourner de valeur, mais <b>afficher</b> les résultats.</li>
        <li>Les lignes vides doivent être gérées correctement.</li>
        <li>Vérifiez que chaque ligne commence bien par son <b>indice</b>.</li>
    </ul>
</div>

<div class="hint">
    <b>Si les tests échouent :</b><br>
    <ul>
        <li>Assurez-vous que chaque ligne est affichée sur une seule ligne.</li>
        <li>Vérifiez que les valeurs sont bien séparées par une <b>espace</b>.</li>
        <li>Testez votre code avec un tableau contenant des lignes vides.</li>
    </ul>
</div>
