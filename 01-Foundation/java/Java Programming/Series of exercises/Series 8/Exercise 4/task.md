# Exercice 4 de la série 8

Une "monotonie" dans un tableau d'entiers est une sous-séquence triée de longueur maximale. Par
exemple, il y a 3 monotonies dans le tableau {3, 1, 4, 6, 2, 9}.
Écrire une méthode qui calcule le nombre de monotonies dans un tableau d'entiers.
