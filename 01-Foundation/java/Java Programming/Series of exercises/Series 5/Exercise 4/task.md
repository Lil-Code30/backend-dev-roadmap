# Exercice 4 de la série 5

Écrire un programme qui recherche et affiche les facteurs premiers d'un nombre entier (> 1) lu au
clavier. Il n'est pas nécessaire que le programme soit efficace (exemple d'amélioration : excepté 2,
inutile de rechercher d'autres diviseurs pairs).
---
**&#9432;**
Afin de tester votre solution correctement, suivez attentivement les
instructions données ci-dessous.
--- 

## Instructions:
Réalisez le programme qui recherche les facteurs premiers de la manière suivante :

- `number` est reçu comme paramètre. Il faut réaliser la recherche pour ce nombre.
- Si le nombre reçu est par exemple `120`, vous devez afficher sur la console `"120 = 2 x 2 x 2 x 3 x 5"`
