# Exercice 2 de la série 5

Écrire et tester sur machine un programme Java qui affiche un motif en "dents de scie".
La méthode reçoit en paramètres le nombre de dents à afficher ainsi que la hauteur maximale
de chaque dent, et doit afficher ensuite le motif correspondant.

## Instructions :

- Pour chaque dent, le programme doit afficher une série de lignes dont le nombre d’étoiles
  augmente de 1 jusqu’à atteindre la hauteur maximale.
- **Exemple :** Pour 3 dents de hauteur 4, le résultat attendu est :

```
*
**
***
****
*
**
***
****
*
**
***
****
```

<div class="hint">
 Utilisez des boucles imbriquées :<br>
- Une boucle extérieure pour répéter l'affichage pour chaque dent.<br>
- Une boucle intérieure pour afficher les lignes d'une dent, en augmentant progressivement le nombre d’étoiles.
</div>
