# Exercice 1 de la série 3

Écrire un programme qui reçoit comme paramètres la longueur des trois côtés 
d'une triangle et qui affiche son périmètre si le triangle est valide. Sinon,
le programme affichera un message d'erreur.

---
**&#9432;**
Afin de tester votre solution correctement, suivez attentivement les
instructions données ci-dessous.
--- 
## Instructions :
Réalisez le programme pour le calcul du périmètre d'un triangle :
- La longueur des trois côtés sont reçus comme paramètres à la méthode `main` et
  convertis en nombre `double`.
- Si le triangle est valide, vous devez afficher sur la console `"Perimeter 
of triangle ("+a+", "+b+", "+c+") = ...` avec la valeur du périmètre.
- Si le triable n'est pas valide, vous devez afficher sur la console `"*The 
  triangle ("+a+", "+b+", "+c+") is not valid"`.
