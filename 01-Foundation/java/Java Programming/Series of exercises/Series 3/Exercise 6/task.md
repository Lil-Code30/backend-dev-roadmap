# Exercice 6 de la série 3
Écrire un programme qui stocke dans la variable r la valeur maximale parmi les variables a, b, c.

---
**&#9432;**
Afin de tester votre solution correctement, suivez attentivement les
instructions données ci-dessous.
---

## Instructions :
- `a`, `b` et `c` sont reçues comme paramètres à la méthode `main` et
  converties en nombre `int`.
- Lorsque le plus grand nombre entre `a`, `b`, et `c` est `10` par exemple, le programme
  doit afficher le résultat sous la forme suivante : `"Maximum is: 10"` sur la console.
