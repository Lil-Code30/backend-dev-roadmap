# Exercice 7 de la série 6

Écrire une méthode `approximatePi()` qui calcule une approximation de π
en utilisant la série suivante (la valeur m sera
passée en paramètre) :
π = 4 (1 – 1/3 + 1/5 – 1/7 + 1/9 – 1/11 + ... – 1/(4m–1) + 1/(4m+1))

<div class="hint">
    <b>Vérifiez votre implémentation</b><br>
    <ul>
        <li>La méthode doit prendre un entier positif en paramètre.</li>
        <li>Elle doit retourner un nombre en virgule flottante (<code>double</code>).</li>
        <li>Utilisez une boucle pour accumuler les termes de la série.</li>
    </ul>
</div>

<div class="hint">
    <b>Si les tests échouent :</b><br>
    <ul>
        <li>Assurez-vous que votre méthode porte bien le nom <b>approximatePi</b>.</li>
        <li>Vérifiez que votre paramètre est bien de type <b>int</b>.</li>
        <li>Votre méthode doit retourner un <b>double</b> et non afficher directement le résultat.</li>
    </ul>
</div>
