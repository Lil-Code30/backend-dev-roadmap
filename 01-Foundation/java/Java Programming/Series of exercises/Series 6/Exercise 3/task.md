# Exercice 3 de la série 6

Écrire deux méthodes permettant de comparer des nombres entiers en utilisant la **surcharge de méthodes**.

## Instructions :

### **1. Méthode `max(int a, int b)`**
- **Paramètres :** Deux nombres entiers `a` et `b`.
- **Objectif :** Retourner le maximum des deux valeurs fournies.

### **2. Méthode `max(int a, int b, int c, int d)`**
- **Paramètres :** Quatre nombres entiers `a`, `b`, `c` et `d`.
- **Objectif :** Retourner le maximum des quatre valeurs fournies.

### **3. Contraintes et recommandations**
- Les deux méthodes doivent porter le même nom (`max`) pour démontrer la **surcharge de méthodes**.
- Aucune fonction prédéfinie de comparaison ne doit être utilisée (pas de `Math.max`).

<div class="hint">
    <b>Si les tests échouent :</b>
    <ul>
        <li>Assurez-vous que votre méthode s'appelle bien <code>max</code> et non <code>Max</code>, <code>maximum</code>, etc.</li>
        <li>Vérifiez que les types des paramètres sont corrects.</li>
        <li>Si vous obtenez une erreur "cannot find symbol max", cela signifie que la signature attendue est incorrecte.</li>
        <li>Regardez attentivement l'ordre et le type des paramètres si une méthode n'est pas reconnue.</li>
    </ul>
</div>
