# Exercice 6 de la série 6

Écrire une méthode qui calcule la somme des chiffres
d'un nombre entier positif.
---
**&#9432;**
Afin de tester votre solution correctement, suivez attentivement les
instructions données ci-dessous.
--- 


## Instructions :
Réalisez le programme qui calcule la somme des chiffres d'un nombre de la manière suivante :

- Implémentez la méthode `sumDigits(...)`. (Attention à bien utiliser ce nom de méthode !)

<div class="hint">
    <b>Exemple</b><br>
    <ul>
        <li><code>sumDigits(123)</code> doit retourner <code>6</code> car 1 + 2 + 3 = 6.</li>
        <li><code>sumDigits(9875)</code> doit retourner <code>29</code> (9 + 8 + 7 + 5).</li>
    </ul>
</div>

<div class="hint">
    <b>Si les tests échouent</b><br>
    <ul>
        <li>Vérifiez que votre méthode prend bien <b>un seul paramètre</b> de type entier.</li>
        <li>Si une erreur indique qu'aucune méthode correspondante n'a été trouvée, 
            <b>assurez-vous que le nom de la méthode est correct</b>.</li>
        <li>Votre méthode doit <b>retourner</b> un entier, et non l'afficher directement.</li>
    </ul>
</div>
